# vps-setup.sh — базовая настройка VPS

Интерактивный bash-скрипт для первоначальной защиты свежего сервера на
Ubuntu (20.04 / 22.04 / 24.04) или Debian. Задаёт вопросы шаг за шагом,
везде предлагает разумные значения по умолчанию (достаточно нажимать
Enter) и объясняет, что именно делает перед каждым действием.

## Что делает скрипт

1. **Обновление системы** — `apt-get update && apt-get upgrade`.
2. **Отключение IPv6** — на уровне ядра через `sysctl`, по желанию.
3. **Защита SSH**:
   - интерактивная смена порта SSH (с поддержкой socket-активации
     `ssh.socket`, которая используется по умолчанию в Ubuntu 24.04);
   - отключение входа по паролю (остаётся только вход по SSH-ключу),
     с проверкой, что у пользователя вообще есть добавленный ключ.
4. **Фаервол UFW** — запрет всех входящих соединений по умолчанию,
   автоматическое открытие нового порта SSH, интерактивный запрос на
   открытие дополнительных портов (80, 443 и любых других).
5. **Fail2Ban** — защита SSH от подбора пароля (по умолчанию: бан на
   1 час после 3 неудачных попыток за 10 минут).

## Как использовать

```bash
wget https://raw.githubusercontent.com/<ваш-репозиторий>/main/vps-setup.sh
sudo bash vps-setup.sh
```

Скрипт нужно запускать **от root** (или через `sudo`) на только что
созданном сервере.

## Важно: как скрипт защищает вас от потери доступа

Смена порта SSH и отключение пароля — рискованные операции: ошибка в
конфигурации может лишить вас доступа к серверу. Поэтому скрипт:

- перед применением новых настроек SSH проверяет их синтаксис
  (`sshd -t`);
- открывает новый порт SSH в фаерволе **до** того, как переключит на
  него SSH-сервер;
- после смены порта или отключения пароля просит вас открыть **новое**
  окно терминала и проверить вход, не закрывая текущую сессию;
- если проверка не удалась — автоматически откатывает изменения порта
  SSH назад.

Тем не менее: **держите открытой текущую SSH-сессию**, пока не
убедитесь, что новая работает. Если у вашего провайдера VPS есть
веб-консоль (VNC/serial console) — держите её под рукой на всякий
случай.

## Требования

- Ubuntu 20.04/22.04/24.04 или Debian (на других системах скрипт
  спросит подтверждение и может работать нестабильно).
- Права root.
- Пакеты `apt`, `systemd`, `ufw`, `fail2ban` — `ufw` и `fail2ban`
  скрипт установит сам, если их ещё нет.

## Журнал

Все действия скрипта дублируются в лог-файл
`/var/log/vps-setup-<дата>.log` — удобно для диагностики, если что-то
пошло не так.
